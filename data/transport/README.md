# 交通・物流の静的ネットワーク

このディレクトリの索引と `public/data/transport/*.geojson` は同じビルドで生成する。国内の路線形状・接続の理解に使い、現在の運行状況・貨物の実経路・全国の完全なサービス網とは扱わない。

## 形状

出典：国土交通省「国土数値情報（高速道路時系列データ N06・鉄道データ N02）」2025年版を加工。ともに2025年12月31日時点。2026年9月16日取得。

- [N06](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N06-2025.html)：**2025年の現況だけ**を使用する。設置開始年 <= 2025 <= 設置終了年、供用開始年 <= 2025 を満たす1,289区間を314名称に集約。歴史全体の再配布ではない。該当する現況利用は CC BY 4.0。
- [N02](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html)：21,933区間を路線名・運営会社で集約。事業者種別1の新幹線9件、それ以外の旅客鉄道・軌道588件。北陸新幹線は会社別に2件であり、「全国9路線」という意味ではない。山形・秋田新幹線の在来線区間は鉄道側。貨物専用線は含まない。CC BY 4.0。
- 線形の単純化：Douglas-Peucker、許容値0.0004度、座標を小数点以下5桁に丸める。拡大時に測量精度を保証するデータではない。
- 原本URL、原本SHA-256、ZIP内パス、加工手順は `provenance.json`。CC BY 4.0のライセンス本文は https://creativecommons.org/licenses/by/4.0/ 。地図に提供元と加工表示、詳細に元資料とライセンスを掲載。

再生成：上記公開ページにある `N06-25_GML.zip` と `N02-25_GML.zip` を同じ入力ディレクトリに置き、`python3 scripts/build-transport-network.py <入力ディレクトリ>` を実行。原本ZIPはリポジトリに含めない。

## 接続・名称

`lib/transport/catalog.ts` は、公開された接続の事実と名称の対応を編集したカタログ。事業者の路線図・地図・時刻表は転載していない。

- ANAの都市間案内から国内6接続を抜粋。
- 商船三井さんふらわあの貨物輸送案内にある国内6航路。フェリーは旅客と貨物、東京〜博多・苅田のROROは貨物として分類。
- 点は港・空港の代表位置。破線の曲線は端点間を結ぶ**模式線**を計算したもの。実際の飛行・航行経路、AIS・航空機位置、航海用データではない。
- 東名・東北自動車道の案内名称をNEXCO資料で補い、原資料上の法令名も保持。区間の形状はN06のまま。
- 事業者の案内の確認日と、形状の対象年月日を別に管理。自動更新や運行確認は行っていない。

## 意味と互換性

`types/transport.ts` で輸送手段、サービス、旅客/貨物、国内外、形状/接続を独立した属性にする。既存の `LiveLogisticsEvent` と道路状況の権利ゲートは維持し、現在情報の未取得を正常運行へ変換しない。

`theme=logistics` は新しい探索画面。`transport`, `region`, `route` で表示状態を共有可能。従来の `selected`、到着/影響レイヤー、旧表示モード、シグナルURLは既存のデモ画面へ戻す。既存IDの変更はない。
